# SemiFog

Official repository for “SemiFog: A Semi-Supervised Framework for Robust Object Detection in Foggy Conditions”, providing the COCO-Fog synthetic foggy object detection dataset and the unlabeled real-world foggy image dataset for research on semi-supervised learning, domain adaptation, and robust object detection under adverse weather conditions.
